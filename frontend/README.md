# AgriMali

AgriMali est une plateforme web qui met en relation directement les agriculteurs et les acheteurs au Mali, sans passer par des intermédiaires.

L'idée est simple : permettre aux agriculteurs de mieux vendre leurs produits et aux acheteurs de trouver facilement ce dont ils ont besoin.

## Fonctionnalités

- Inscription et connexion sécurisées (JWT, mots de passe hashés avec bcrypt)
- Gestion des commandes entre agriculteurs et acheteurs
- Forum pour échanger entre utilisateurs
- Affichage de la météo des villes maliennes
- Mode sombre / mode clair
- Limitation du nombre de requêtes (rate limiting) pour protéger l'API

## Technologies utilisées

- **Frontend** : React + Vite
- **Backend** : Node.js + Express
- **Base de données** : MySQL

## Statut du projet

Le projet est en développement. Des audits de sécurité web ont été réalisés pour améliorer sa fiabilité. Le déploiement est reporté pour le moment.
